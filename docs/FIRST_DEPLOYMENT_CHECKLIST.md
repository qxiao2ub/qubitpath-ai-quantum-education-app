# First Deployment Checklist

- [ ] Extract the ZIP on your computer.
- [ ] Create an empty GitHub repository.
- [ ] Upload every file and folder inside `qubitpath-ai-quantum-education`.
- [ ] Confirm `app.py` and `requirements.txt` are at repository root.
- [ ] Commit to the `main` branch.
- [ ] In Streamlit Community Cloud, choose the repository and `main` branch.
- [ ] Set the main file path to `app.py`.
- [ ] Select Python 3.12 in Advanced settings.
- [ ] Deploy. No secrets are required for the prototype.
